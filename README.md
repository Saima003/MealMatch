# MealMatch

MealMatch is a full-stack MERN application that helps users discover recipes based on the ingredients they already have.

## Features

- Ingredient search and selection
- Category-based ingredient explorer
- Recipe matching algorithm
- Missing ingredient detection
- Pantry ingredient filtering
- Fast recipe search

## Tech Stack

Frontend
- React
- TailwindCSS

Backend
- Node.js
- Express.js

Database
- MongoDB

Deployment
- Vercel
- Render
- MongoDB Atlas

## How It Works

1. Users select ingredients
2. The backend searches recipes containing those ingredients
3. Recipes are ranked by ingredient match
4. Missing ingredients are displayed (excluding pantry items)
